# UMAR.DEV

Сомонаи бисёрсаҳифагӣ бо HTML, CSS ва JavaScript. Ҳамаи саҳифаҳо ва файлҳои зарурӣ дар решаи repository ҷойгиранд; китобхона ё build-и иловагӣ лозим нест.

## Иҷрои маҳаллӣ

Файли `index.html`-ро дар браузер кушоед. Барои санҷидани ҳисобкунак, `calculator.html`-ро кушоед.

## Нашр дар GitHub Pages

1. Repository-и GitHub созед.
2. Ҳамаи файлҳо ва тасвирҳои ҳамин папкаро ба решаи repository бор кунед.
3. Дар **Settings → Pages**, манбаи **Deploy from a branch**-ро интихоб кунед.
4. Branch-и асосӣ ва папкаи `/(root)`-ро интихоб карда, тағйиротро нигоҳ доред.

GitHub Pages баъди анҷоми нашр сомонаро дар суроғаи пешниҳодкардааш дастрас мекунад.
